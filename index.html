EKSPOLORASI GRAFIK FUNGSI KUADRAT

Matematika Kelas X | Kurikulum Merdeka

Geser parameter dan amati perubahan grafik!

1. Tujuan Pembelajaran

  • Memahami bentuk umum fungsi kuadrat.
  • Mengetahui pengaruh parameter a, b, dan c.
  • Mengamati perubahan grafik parabola.
  • Menentukan titik puncak dan sumbu simetri.
f(x) = ax² + bx + c

Pada aktivitas ini, kamu dapat mengubah nilai a, b, dan c menggunakan slider. Perhatikan bagaimana perubahan nilai tersebut memengaruhi bentuk dan posisi grafik.

2. Laboratorium Grafik Interaktif

Geser Parameter

Menentukan arah buka dan lebar parabola.
Memengaruhi posisi sumbu simetri dan titik puncak.
Menentukan titik potong grafik dengan sumbu Y.
Persamaan saat ini:
f(x) = x²
Informasi Grafik

Grafik Fungsi Kuadrat

Garis biru menunjukkan grafik fungsi kuadrat.

3. Amati Perubahan Grafik

Petunjuk kegiatan:
  1. Atur nilai a menjadi 1, kemudian ubah menjadi 2 dan 3.
  2. Amati perubahan lebar parabola.
  3. Ubah nilai a menjadi -1 dan -2. Amati arah buka parabola.
  4. Kembalikan nilai a menjadi 1, lalu geser nilai b.
  5. Ubah nilai c dan amati perubahan titik potong sumbu Y.

Pertanyaan Pengamatan

  1. Apa yang terjadi ketika nilai a semakin besar dan positif?
  2. Apa perbedaan grafik ketika nilai a positif dan negatif?
  3. Bagaimana perubahan grafik ketika nilai b diubah?
  4. Bagaimana pengaruh nilai c terhadap titik potong sumbu Y?
  5. Apakah perubahan parameter memengaruhi titik puncak parabola?

4. Kesimpulan Materi

  • Parameter a: menentukan arah buka dan tingkat kelengkungan parabola. Jika a positif, grafik terbuka ke atas. Jika a negatif, grafik terbuka ke bawah.
  • Parameter b: bersama a menentukan sumbu simetri dan posisi titik puncak.
  • Parameter c: menentukan titik potong grafik dengan sumbu Y, yaitu (0,c).
x titik puncak = -b / 2a
y titik puncak = f(-b / 2a)
